# Desktop Parity Policy

## Keep

- 音声合成
- 複数モデル管理
- モデルの load / unload
- パラメータ調整
- アクセント編集
- 辞書
- プリセット
- プロジェクト保存 / 読込
- WAV 書き出し
- 設定 / ヘルプ

## Redesign For Mobile

- ホットキー
- ウィンドウ操作
- 外部 engine 実行ファイル管理
- VVPP 管理
- desktop 固有の多窓 UI

## Shared Rule

OS ごとの実装差があっても、保存形式と fixture に対する入出力は `shared/` を正とする。
